# Algoritmos y Sistemas Computacionales (IIC1001) — mapa del curso

Vault de estudio del ramo. Las notas están escritas para alguien que llega desde cero: cada concepto parte de un problema concreto, sigue con ejemplos y termina con preguntas de repaso. Dentro de cada carpeta, el número del archivo indica el orden de lectura.

## Cómo están hechas las notas
- **Frontmatter:** `ramo`, `tema`, `tags` y `prerrequisitos` (notas que conviene leer antes).
- **Cuerpo:** explicación paso a paso, tablas para comparar, diagramas Mermaid y ejemplos breves.
- **Imágenes:** figuras del material del curso en PNG, con su transcripción en un callout plegable.
- **Cierre:** preguntas de repaso con la respuesta oculta.

## Ruta de estudio sugerida
1. **Introducción → Representación numérica:** cómo se guarda la información y cómo se traduce a bits.
2. **Operaciones binarias → Codificación:** cómo opera el computador con esos bits y cómo representa texto.
3. **Compuertas lógicas → Circuitos sumadores:** cómo se construyen operaciones con transistores.
4. **Multiplexores → Programabilidad:** cómo se pasa de circuitos fijos a un computador programable.
5. **Sistemas operativos:** cómo el software administra el hardware.
6. **Complejidad → Grafos:** las herramientas algorítmicas para resolver problemas.
7. **Gestión del curso:** evaluaciones y qué entra en cada una.

Lo que sigue después de este ramo: [[Estructuras de Datos/_Índice|Estructuras de Datos]] (algoritmos y su eficiencia) y [[Sistemas Operativos y Redes/_Índice|Sistemas Operativos y Redes]] (el hardware y el software del computador en profundidad).
