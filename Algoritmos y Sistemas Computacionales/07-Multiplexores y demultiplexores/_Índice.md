# Multiplexores y demultiplexores — índice

Cómo se seleccionan y distribuyen datos en un circuito: el multiplexor elige una entrada, el demultiplexor dirige una salida y la ALU usa la misma idea para elegir operaciones.

Volver al [[Algoritmos y Sistemas Computacionales/_Índice|mapa del ramo]].

## Orden de estudio
1. [[01 - Multiplexor (MUX)|Multiplexor (MUX)]]: elegir una de varias entradas y las líneas de selección.
2. [[02 - Demultiplexor (DEMUX)|Demultiplexor (DEMUX)]]: dirigir una entrada a una de varias salidas.
3. [[03 - Unidad de selección y ALU|Unidad de selección y ALU]]: seleccionar operaciones y el primer paso hacia un computador programable.
