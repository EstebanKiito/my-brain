# Primeros pasos en Python — índice

Cómo se escribe y ejecuta un programa en Python, cómo pedir datos y guardarlos en variables, los tipos básicos (`int`, `float`, `str`, `bool`), los operadores aritméticos y de comparación y el uso de funciones predefinidas y del módulo `random`.

Volver al [[Introducción a la Programación/_Índice|mapa del ramo]].

## Orden de estudio
1. [[01 - Python, IDLE y el primer programa|Python, IDLE y el primer programa]]: `print`, comentarios, sintaxis y semántica.
2. [[02 - Variables, input y conversión de tipos|Variables, input y conversión de tipos]]: asignación, `input`, `int`/`float`/`str` y f-strings.
3. [[03 - Operadores aritméticos|Operadores aritméticos]]: `//`, `%`, `**`, prioridad y sorpresas con decimales.
4. [[04 - Funciones predefinidas, random y booleanos|Funciones predefinidas, random y booleanos]]: funciones que devuelven valores, `random.randint`, comparaciones y `type`.
