# Tecnologías web adicionales — índice

Cuatro tecnologías que amplían lo que puede hacer una aplicación web: TypeScript para tener tipos estáticos, WebAssembly para ejecutar código de alto rendimiento en el navegador, WebSockets para la comunicación en tiempo real, y las Progressive Web Apps con service workers para comportarse como una app móvil, incluso sin conexión.

Volver al [[Tecnologías y Aplicaciones Web/_Índice|mapa del ramo]].

> [!note] Origen
> Construido con las slides de la clase de tecnologías adicionales (TypeScript, WebAssembly con Emscripten, Rust y AssemblyScript, APIs de comunicación, WebSockets y Socket.IO, PWAs, manifest y service workers). El código TypeScript se compiló con `tsc` (incluidos los errores esperados) y el servidor de WebSockets se probó con `ws`.

## Orden de estudio
1. [[01 - TypeScript en la práctica|TypeScript en la práctica]]: anotaciones, inferencia, uniones, interfaces, clases, herencia y genéricos.
2. [[02 - WebAssembly|WebAssembly]]: formato binario, compilación desde C y Rust, Emscripten y relación con JavaScript.
3. [[03 - WebSockets y comunicación en tiempo real|WebSockets y comunicación en tiempo real]]: Fetch, WebSocket, SSE y WebRTC; servidor y cliente de eco; Socket.IO.
4. [[04 - Progressive Web Apps y service workers|Progressive Web Apps y service workers]]: manifest, service worker como proxy, ciclo de vida y caché offline.
