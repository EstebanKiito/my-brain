# HTML y CSS — índice

Las dos tecnologías con que se describe una página: HTML para la estructura y el significado del contenido, y CSS para su presentación. Cierra con lo que hace el navegador con ambos para llegar a los píxeles en pantalla (DOM, CSSOM y critical rendering path).

Volver al [[Tecnologías y Aplicaciones Web/_Índice|mapa del ramo]].

> [!note] Origen
> Basado en los apuntes de clase (definiciones de HTML y CSS, modelo de caja, DOM y CSSOM) y completado con las slides de la clase de HTML y CSS (historia de ambos, anatomía de elementos y reglas, tags, HTML5, selectores, formas de insertar CSS, cascada y critical rendering path).

## Orden de estudio
1. [[01 - Anatomía de un documento HTML|Anatomía de un documento HTML]]: elementos, atributos, esqueleto del documento y tags más usados.
2. [[02 - HTML5 y estructura semántica|HTML5 y estructura semántica]]: `header`, `nav`, `article`, audio, video y SVG nativos.
3. [[03 - Reglas, selectores y cascada en CSS|Reglas, selectores y cascada en CSS]]: anatomía de una regla, selectores, CSS externo, interno e inline, y prioridades.
4. [[04 - Modelo de caja|Modelo de caja]]: margin, border, padding y contenido; cómo se calcula el tamaño.
5. [[05 - DOM, CSSOM y critical rendering path|DOM, CSSOM y critical rendering path]]: de los bytes al árbol, y del árbol a la pantalla.
