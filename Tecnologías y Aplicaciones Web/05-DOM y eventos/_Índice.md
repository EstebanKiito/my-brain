# DOM y eventos — índice

Cómo JavaScript se comunica con la página: encontrar nodos en el árbol del DOM y moverse entre ellos, crear y modificar elementos para construir HTML dinámicamente, y reaccionar a lo que hace el usuario con eventos y event listeners.

Volver al [[Tecnologías y Aplicaciones Web/_Índice|mapa del ramo]].

> [!note] Origen
> Basado en los apuntes de clase (HTML DOM, jerarquía y búsqueda de nodos, propiedades, ejecución de JS desde HTML, control del DOM, eventos y objeto Event) y completado con las slides de la segunda clase de JavaScript (métodos de contenido y estilo, diagrama de propiedades de nodos, propagación con capturing y bubbling). El código se probó con Node.js y jsdom.

## Orden de estudio
1. [[01 - Buscar y recorrer nodos del DOM|Buscar y recorrer nodos del DOM]]: `getElementById`, `querySelector*`, `getElementsBy*`, colecciones vivas y propiedades de nodos.
2. [[02 - Crear y modificar elementos del DOM|Crear y modificar elementos del DOM]]: `<script>`, `createElement`, `appendChild`, atributos, `textContent` e `innerHTML`.
3. [[03 - Eventos y event listeners|Eventos y event listeners]]: tipos de eventos, `addEventListener`, el objeto `Event`, `target`, `currentTarget` y propagación.
