# CSS moderno — índice

El diseño web llevado al código: por qué el mismo CSS se ve distinto según el navegador y qué unidades usar, las capacidades nativas del CSS actual (variables, anidamiento, selectores nuevos), el layout con Flexbox y Grid, las animaciones, y las herramientas que aceleran el trabajo (Bootstrap, Sass, Less, Tailwind y design systems).

Volver al [[Tecnologías y Aplicaciones Web/_Índice|mapa del ramo]].

> [!note] Origen
> Construido con las slides de la clase de diseño web en la práctica (motores de rendering, reset, unidades, variables, nesting, selectores, Flexbox, Grid, transition, transform, animation, keyframes, Bootstrap, Sass, Less, Tailwind, Three.js y design systems). Los ejemplos de Sass y Less se compilaron y los bloques CSS se validaron sintácticamente.

## Orden de estudio
1. [[01 - Rendering entre navegadores y unidades CSS|Rendering entre navegadores y unidades CSS]]: Blink, Gecko y WebKit, reset CSS, Can I Use, `px`, `em`, `rem`, `vw` y `vh`.
2. [[02 - Variables, anidamiento y selectores modernos|Variables, anidamiento y selectores modernos]]: custom properties, `&`, combinadores, `:is`, `:not` y `:has`.
3. [[03 - Flexbox y Grid|Flexbox y Grid]]: layout en una y dos dimensiones, propiedades principales y cuándo usar cada uno.
4. [[04 - Animaciones en CSS|Animaciones en CSS]]: `transition`, `transform`, `animation` y `@keyframes`.
5. [[05 - Frameworks de CSS y design systems|Frameworks de CSS y design systems]]: Bootstrap, Sass, Less, Tailwind, Material Design y Storybook.
