# Construir una API con Express — índice

El backend del curso paso a paso: armar un proyecto Node con Express y nodemon, organizar los endpoints en routers, configurar Sequelize y PostgreSQL (también en macOS con Homebrew) y crear el primer recurso con modelos, migraciones, seeds y rutas CRUD.

Volver al [[Tecnologías y Aplicaciones Web/_Índice|mapa del ramo]].

> [!note] Origen
> Construido con las slides de la clase "Mi primera API" (package.json, node_modules, Hello world con nodemon, primer router, configuración de Sequelize y Postgres, primer recurso, próximos pasos y limpieza) y con lo genérico de los apuntes de tareas y proyecto: el flujo de sequelize-cli, la configuración de Postgres con Homebrew y el patrón de router índice, reescritos con el ejemplo neutro de películas. Todo el flujo se reprodujo contra PostgreSQL 14 local.

## Orden de estudio
1. [[01 - Estructura de un proyecto Node con Express|Estructura de un proyecto Node con Express]]: `package.json`, `node_modules`, Hello world, nodemon y estructura de carpetas.
2. [[02 - Rutas y routers en Express|Rutas y routers en Express]]: params, query y body, routers por recurso, router índice y códigos de respuesta.
3. [[03 - Configurar Sequelize y PostgreSQL|Configurar Sequelize y PostgreSQL]]: CLI, `.sequelizerc`, usuario y base en Postgres, Homebrew y `config.json`.
4. [[04 - Modelos, migraciones y seeds con Sequelize|Modelos, migraciones y seeds con Sequelize]]: `model:generate`, `db:migrate`, seeds y rutas con el modelo.
