# React — índice

La librería con que se construye el frontend del curso: qué es React y cómo funcionan JSX y el Virtual DOM, cómo se piensa una interfaz en componentes con props y state, cómo se manejan los eventos y el ciclo de vida, los hooks principales y cómo se arma un proyecto con npm y Vite.

Volver al [[Tecnologías y Aplicaciones Web/_Índice|mapa del ramo]].

> [!note] Origen
> Basado en los apuntes de clase (React, componentes, rendering, elementos, JSX, Virtual DOM, tipos de componentes, props, state, eventos, ciclo de vida y hooks, con sus capturas) y completado con las slides de la clase de React (cuándo usarlo, createElement, cómo empezar una interfaz, aplicación mínima, familias de hooks, npm y Vite). El código se compiló con esbuild y se ejecutó con React 19 y jsdom.

## Orden de estudio
1. [[01 - React, JSX y Virtual DOM|React, JSX y Virtual DOM]]: librería de vista, componentes, rendering, elementos, JSX y diff del Virtual DOM.
2. [[02 - Componentes, props y state|Componentes, props y state]]: componentes funcionales, cómo empezar una interfaz, props, `useState` y aplicación mínima.
3. [[03 - Eventos y ciclo de vida en React|Eventos y ciclo de vida en React]]: `onClick`, handlers como props y fases de montaje, actualización y desmontaje.
4. [[04 - Hooks useState, useContext y useEffect|Hooks useState, useContext y useEffect]]: estado, contexto, efectos, dependencias y limpieza.
5. [[05 - Un proyecto React con npm y Vite|Un proyecto React con npm y Vite]]: `package.json`, `node_modules`, Vite y estructura de un proyecto.
