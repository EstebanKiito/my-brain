# APIs web y REST — índice

Cómo se comunica un cliente con el servidor para obtener datos: qué es una API y una API web, cómo se organizan las operaciones CRUD según los principios REST, cómo se autentica a un usuario con tokens si HTTP no tiene estado, y cómo se documenta y se consume una API desde código.

Volver al [[Tecnologías y Aplicaciones Web/_Índice|mapa del ramo]].

> [!note] Origen
> Basado en los apuntes de clase (definición de API: exponer y consumir) y completado con las slides de la clase de consumo de APIs (API web, CRUD, principios REST, autenticación con tokens, documentación, OpenAPI, AJAX, XMLHttpRequest, fetch, Axios y Postman). Los ejemplos se probaron con Node.js contra la API de GitHub y jsonplaceholder.

## Orden de estudio
1. [[01 - APIs y APIs web|APIs y APIs web]]: exponer y consumir, endpoints, JSON y la aplicación web moderna.
2. [[02 - CRUD y principios REST|CRUD y principios REST]]: operaciones sobre recursos, métodos HTTP, principios REST y `PUT` frente a `PATCH`.
3. [[03 - Autenticación con tokens en APIs|Autenticación con tokens en APIs]]: access token, flujo de login, header `Authorization` y revocación.
4. [[04 - Documentar y consumir APIs|Documentar y consumir APIs]]: documentación, OpenAPI, APIs no documentadas, AJAX, `fetch` y Axios.
