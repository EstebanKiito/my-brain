# Índice — Métodos de escalabilidad

Las familias de métodos para escalar: **dimensionales** (vertical y horizontal, con balanceo y sus costos), **modelación de sistemas** (componentes, conectores, configuraciones y las reglas de Instagram) y los frentes de **distribución por dominio, serverless, frontend y nube**.

2. [[02 - Modelación de sistemas para escalar]] — Reglas para componentes, conectores y configuraciones, estilos que escalan bien y las ocho prácticas de Instagram.
3. [[03 - Distribución serverless frontend y nube]] — Servicios por dominio con API Gateway, serverless y sus riesgos, buenas prácticas de frontend con Core Web Vitals y la nube como bala de oro.
